The app draws the wordmark with `src/components/Wordmark.tsx`, which takes its two colours from `src/styles/tokens.css` (`--color-text` for the letters, `--color-mint` for the bubble). The app is light only, so it draws the light version; `wordmark-dark.svg` is for dark grounds outside the app. The sprout mark stays in the app as `SproutMark` (the loading screen).

# Content attribution

Where PuhuScribe v3's learning content truly comes from. Written in job 7-content-pipeline and carried forward from v2's `docs/content-attribution.md` at commit `9c8d0a0` (`9c8d0a083d6209e0135efe20f88db99ff9c867e4`). Like v2's file, it describes what is true today. v2 once labelled content generated by an AI as Creative Commons material, which caused its content problems.

## Dialogues, word cards and "why" lines

Every dialogue line, word card name and "why" line in v3 is original content made for PuhuScribe:

- Claude (Anthropic API) drafts the spoken and written Finnish, the English meaning and the "why" lines at build time (`scripts/generate/providers/ai.py`).
- Voikko analyses every written word; a form's name comes from Voikko's own reading through a fixed table, never from the AI.
- The native reviewer approves or corrects every line, word card and audio clip before anything is published.

None of it comes from a Creative Commons corpus, and none of it is labelled as such.

## Audio

| Kind | Source |
| --- | --- |
| Synthetic | Azure neural text to speech, fi-FI voices, made at build time (`scripts/generate/providers/voice.py`) |
| Native recordings | Recorded for PuhuScribe on the owner's instruction, in `content/recordings/` |

The review page marks which kind each clip is.

## Material used only at build time

| Material | Source and licence | Use |
| --- | --- | --- |
| `data/finnish_frequency_lemmas.json` | Built in v2 from wordfreq's "large" Finnish data with Voikko. Its own metadata credits wordfreq (MIT) and SUBTLEX. The wordfreq README says its data is CC BY-SA 4.0 | Chooses which words a brief may use (the rank cap). Never shipped to learners |
| Voikko (libvoikko and voikko-fi) | voikko.puimula.org | A tool on the build machine. Nothing of it ships |

v2's file said Leipzig (CC BY 4.0) is the only frequency source. The list v3 imported was built from wordfreq instead, so this is flagged here. Because the list is used only to choose words and is never shipped, no attribution line is shown to learners, but this has not been checked with a lawyer.

## Excluded source

The Kotus "Frequency Lexicon of Finnish Newspaper Language" (CC BY-NC-ND) stays excluded, as in v2: its NonCommercial and NoDerivatives terms do not fit a commercial app.

## Not used in v3 yet

Tatoeba sentences and audio (CC BY 2.0 FR) and the Leipzig Corpora Collection (CC BY 4.0), named in v2's file, are not used in v3. If a later job uses them, their attribution lines from v2's file apply.

# Review batch 1: units 1 to 3

Thank you for checking these dialogues. They are the first three units of PuhuScribe, an app that teaches adult newcomers in Finland the Finnish people actually speak. Each dialogue has a spoken Finnish version (puhekieli) and a written Finnish version (kirjakieli), both read by a synthetic voice. Nothing here reaches a learner until you approve it.

Open each file in Chrome, Safari or Firefox on a computer. Each page works offline and saves nothing until you press "Download my review".

## What to do on each page

1. Read each line in spoken and written Finnish, with its English meaning. Approve it, or choose Fix and write the corrected text.
2. Play every clip. Mark it "Sounds right" or "Sounds wrong". The spoken clips are a synthetic voice reading spoken Finnish, so please say if any sounds unnatural.
3. Check each word card: the base form, the form name and the one line "why". Approve it, or choose Fix and write the correction.
4. Answer the question about the dialogue as a whole. If you asked for any fix, answer "Not yet": you will see only the changed lines again in a short second round.
5. Write your reviewer code, for example R1. Please do not write your name or email address in the page.
6. Press "Download my review". It saves one small file named `review-<dialogue>-round-1.json`.

The spoken Finnish should be standard spoken Finnish as an adult in Helsinki speaks it today, with no dialect and no dated slang. Please fix anything that sounds unnatural, wrong for a beginner, or not how people talk.

## Time

About 20 to 30 minutes per dialogue, so about 2 to 3 hours for all six. This is an estimate.

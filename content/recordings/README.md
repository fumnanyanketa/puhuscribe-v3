# Native recordings

A native speaker's recording replaces the synthetic audio of one line and register. Put it at `content/recordings/<dialogue-slug>/<line>-<register>.mp3`, where register is `puhe` (spoken) or `kirja` (written). The next pipeline run uses it, and the review page marks it "Native recording". How it works: [docs/content-pipeline.md](../../docs/content-pipeline.md).

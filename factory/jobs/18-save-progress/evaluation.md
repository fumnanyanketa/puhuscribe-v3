## Checks of the builder's departures

- **`SaveNoteDb` as its own interface.** Fine. The spec asks for the call on "the learner database module": `supabaseLearnerDb` returns `LearnerDb & ReviewDb & SaveNoteDb`, so the real module has the method. The only effect is that an older test fake without the method gets the real client, which in production is the only case there is. It cannot reach any other client than the learner's own. The fake in `worker/test-fakes.ts` answers `'none'` by default as the statement asks.
- **Statement 8 test seeds the `first_session_completed` event.** Justified. With only two earlier session rows, `complete_session` would write the event for the session under test, and the function would say `'first'`. The helper writes the event for the earliest finished session, as job 8 would have done. The statement's own fallback text leaves this out, but the seeded data is what a real guest has.
- **`document.cookie` is empty.** The statement says it "holds only the sign in cookie". The sign in cookie is HttpOnly, so no script can read it. The test asserts `document.cookie === ''` and that every cookie the browser context holds starts with `puhuscribe-auth`. That is stricter than the statement can be. It does not check that the context holds a cookie at all, so it could pass on an empty list. This is a small gap, and the guest could not have reached the finish screen without the cookie.
- **The `pageshow` guard.** Untested by any CI test, as `build.md` says. I tried a real back forward restore in Chromium (with the cache switched on) and in WebKit through Playwright. Neither browser restored from the cache (the page event said `persisted: false` and the page reloaded), so I cannot prove it that way. With a synthetic `pageshow` event with `persisted = true` the note is removed, the status line stays, and nothing else changes (`eval-browser-checks.txt`, both browsers). The statement's own test (Back shows no note) passes without the guard, because the app starts a new session after a reload. I judge the guard correct and harmless, and statement 7(b) passes. A real iPhone could be checked by hand once.
